Complete Data Flow Pipeline

1 Route Definition - User selects origin/destination in Route Optimizer module
2 Route Calculation - Optimal path computed through charging stations
3 Waypoint Generation - CAV Route Sampler creates 50m interval points
4 Feature Detection - Feature Detector identifies road characteristics
5 Image Acquisition - Street View Capture downloads imagery
6 Object Detection - YOLO Detector processes images for features
7 Risk Visualization - Risk Map displays integrated results with color-coded markers
