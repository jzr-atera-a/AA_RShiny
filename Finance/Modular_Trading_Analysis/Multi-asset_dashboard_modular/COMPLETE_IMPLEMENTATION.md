## 🎯 Usage Instructions

### Quick Start
```r
# 1. Extract the ZIP
unzip asset_dashboard_COMPLETE.zip
cd asset_dashboard_modular_fixed

# 2. Install required packages
install.packages(c(
  "shiny", "shinydashboard", "plotly", "DT", 
  "dplyr", "lubridate", "quantmod", "TTR", 
  "tidyr", "zoo", "corrplot", "shinycssloaders",
  "R6", "yaml", "purrr"
))

# 3. Run the dashboard
shiny::runApp()
```
