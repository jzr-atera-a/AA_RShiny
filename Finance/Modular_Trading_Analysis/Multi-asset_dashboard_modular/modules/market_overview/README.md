# Market Overview Module

## Description
Provides real-time market data overview with interactive price charts, volume analysis, and key statistics.

## Features
- Real-time price and volume charts
- Configurable moving averages
- Market statistics (mean, median, range, volatility)
- Price and returns distributions
- Value boxes for quick insights

## Dependencies
- plotly
- DT
- TTR
- dplyr

## Usage
This module automatically loads when asset data is available through the DataManager.

## Configuration
- Adjust MA period from 5 to 200 days
- Toggle price, volume, and MA display
- Refresh data on demand
