🚀 INSTALLATION - 3 STEPS
═══════════════════════════════════════════════════════════════════════════

STEP 1: Extract the ZIP file
────────────────────────────────────────────────────────────────────────────
Extract MLTradingApp.zip to a location of your choice.

Windows:  Right-click → Extract All
Mac:      Double-click the zip file
Linux:    unzip MLTradingApp.zip


STEP 2: Install R Packages
────────────────────────────────────────────────────────────────────────────
Open R or RStudio, navigate to the MLTradingApp folder, and run:

    source("setup.R")

This will automatically install all required packages:
  ✓ shiny
  ✓ shinydashboard
  ✓ plotly
  ✓ DT
  ✓ dplyr
  ✓ ggplot2


STEP 3: Run the App
────────────────────────────────────────────────────────────────────────────
    shiny::runApp()

Or in RStudio:
  1. Open app.R
  2. Click "Run App" button in top-right corner

📖 ADDING MORE CHAPTERS (CHAPTERS 4-25)
═══════════════════════════════════════════════════════════════════════════

The app is designed for easy extension. To add a new chapter:

1. Copy the template:
   cp templates/chapter_template.R modules/chapter04.R

2. Edit chapter04.R:
   - Update chapter number, title, subtitle
   - Add your content
   - Create visualizations

3. Register in app.R (add 3 lines):
   menuItem("Ch 4 · Your Title", tabName = "ch4", icon = icon("flask"))
   tabItem(tabName = "ch4", chapter4_ui("ch4"))
   chapter4_server("ch4")

4. Refresh the app - your chapter appears!

See docs/EXTENSION_GUIDE.md for detailed step-by-step instructions.

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Error: "Could not find function 'chapter1_ui'"
→ Restart R session: .rs.restartR() in RStudio
→ Check you're in the correct directory

Error: Package not found
→ Run: source("setup.R")

Plots not showing
→ Clear browser cache (Ctrl+Shift+R)
→ Update plotly: install.packages("plotly")

For more solutions, see docs/TROUBLESHOOTING.md
