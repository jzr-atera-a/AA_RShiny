# DEBUG LOGGING INSTRUCTIONS

## Files Changed:
1. https_server.py - NOW HAS DEBUG LOGGING!
2. trajectory_6modes.html - SENDS DEBUG LOGS TO SERVER

## How to Use:

### 1. Start the HTTPS server:
```bash
python https_server.py
```

### 2. The server will create a file: `ar_debug.log`

### 3. Watch the logs in real-time:
```bash
# In another terminal window:
tail -f ar_debug.log
```

OR just open `ar_debug.log` in a text editor and refresh to see updates

### 4. On Quest 3, visit the AR page as normal

### 5. All debug info will be written to `ar_debug.log`

## If You See Errors:

ERROR messages will show what went wrong, for example:
```
[2026-02-27 20:45:14.678] ERROR: GeoJSON load failed: Failed to fetch
```

This means the geojson file is missing or can't be loaded.
