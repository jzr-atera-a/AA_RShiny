================================================================================
QUICK REFERENCE: MAGIC PHRASES
================================================================================

Use these phrases to get exactly what you need:

"Maximum 1500 lines per block"
→ Prevents truncation, forces me to split appropriately

"Tell me upfront how many parts"
→ No surprises, you know what's coming

"Raw code only, no explanations between blocks"
→ Stops me from adding commentary you don't need

"Complete working code, not just updates"
→ Gets full code, not partial fixes

"Number each block (Part 1/3, Part 2/3, Part 3/3)"
→ Easy to track and assemble

"Copy-paste ready"
→ Ensures proper formatting and syntax

"Break at logical boundaries"
→ Splits happen between functions, not mid-code

"DO NOT give me [X], DO give me [Y]"
→ Crystal clear instructions on what you want/don't want

================================================================================
ANTI-PATTERNS (WHAT NOT TO SAY)
================================================================================

❌ "Give me the code" 
   → Too vague, I might truncate or give partial code

❌ "Show me what to change"
   → You'll get instructions, not code

❌ "Fix this"
   → Might get explanation instead of fixed code

❌ "Update the app"
   → Ambiguous, might give partial updates

❌ No size limit specified
   → Risk of truncation at ~2000 lines

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: Code gets truncated/cut off
SOLUTION: Add "maximum 1500 lines per block" to your request

PROBLEM: You get explanations instead of code
SOLUTION: Add "raw code only, no explanations"

PROBLEM: You get partial code/updates instead of complete code
SOLUTION: Add "give me COMPLETE working code, not just changes"

PROBLEM: Code arrives in confusing chunks
SOLUTION: Add "tell me upfront how many parts" and "number each part"

PROBLEM: I give you instructions instead of code
SOLUTION: Say "DO NOT give me instructions, DO give me complete code"

PROBLEM: Code breaks are in weird places (mid-function)
SOLUTION: Add "break at logical boundaries between functions/sections"
