## Critical Enable/Disable Logic

The system MUST work exactly like this:

```yaml
# modules/_module_registry.yml - THE CONTROL CENTER
modules:
  module_name:
    enabled: false  # ← Change ONLY this line to disable
    priority: 10    # Load order (1-99, lower first)
```

**When `enabled: false`:**
- ✅ Files NOT sourced (ui.R, server.R not loaded)
- ✅ Packages NOT loaded (dependencies skipped)
- ✅ NOT in sidebar menu
- ✅ NOT in dashboard body tabs
- ✅ Server function NOT called
- ✅ ZERO performance overhead (as if module doesn't exist)

**When `enabled: true`:**
- ✅ Module fully active
- ✅ Appears in menu
- ✅ Tab rendered
- ✅ Packages loaded
- ✅ Server initialized

## Migration Rules - FROM OLD TO NEW

For each existing tab in my old app:

1. **File Structure:**
   - `Tabs/Tab_Name.R` → `modules/tab_name/`
   - Create `manifest.yml`, `ui.R`, `server.R`, `README.md`

2. **Library Calls:**
   - `library(package)` in old file → `dependencies: packages: [package]` in manifest.yml
   - Remove ALL library() calls from module files

3. **UI Function:**
   - `UI_Tab_Name <- tabItem(...)` → `tab_name_ui <- function(id) { ns <- NS(id); tagList(...) }`
   - Wrap ALL IDs with `ns()`

4. **Server Function:**
   - `Server_Tab_Name <- function(input, output)` → `tab_name_server <- function(id, api_manager) { moduleServer(id, function(...) { }) }`

5. **IDs:**
   - Change dots to underscores: `input$control.success` → `input$control_success`
   - Wrap in UI: `textInput("my_input", ...)` → `textInput(ns("my_input"), ...)`

6. **CSS:**
   - Remove ALL inline CSS from R files
   - Move to `www/css/global.css`

## Naming Conventions - STRICT

- **Module ID:** `lowercase_with_underscores` (e.g., `ab_testing`)
