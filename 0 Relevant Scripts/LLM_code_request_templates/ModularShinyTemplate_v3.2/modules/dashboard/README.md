# Dashboard Module

## Description
Main dashboard showing overview, metrics, and system status.

## Features
- Value boxes with key metrics
- Sample visualization
- System status display
- Welcome message with quick start guide

## Dependencies
- shiny
- shinydashboard
- ggplot2

## Outputs
- Value boxes for metrics
- Sample line chart
- System information display

## Customization
- Edit value box calculations in server.R
- Replace sample chart with your own data
- Add more rows/boxes as needed
