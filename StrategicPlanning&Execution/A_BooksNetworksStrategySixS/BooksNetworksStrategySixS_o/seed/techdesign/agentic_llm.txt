design_id: seed_agentic_llm
design_group: ml_genai
design_type: agentic_llm
title: Agentic LLM System
variant: Plan, act, observe loop with guardrails
summary: An agentic system lets an LLM pursue a goal over several steps. A planner decomposes the goal, an executor calls tools and observes the results, and a critic reflects and revises the plan. Memory keeps context across steps while guardrails and human approval limit what the agent may do.
when_to_use: Tasks need multiple steps, tool use or decisions that depend on intermediate results, such as research, data analysis, coding or workflow automation.
when_not_to_use: A single prompt or a fixed workflow solves the task; agents add latency, cost and unpredictability.
complexity: High
tags: agents, tool use, react, planning, memory, guardrails

@step
order: 1
text: The user submits a goal through the Agent API.
components: C1,C2

@step
order: 2
text: The planner asks the LLM for a plan, using system policy and recalled long-term memory.
components: C3,C6,C7,C14

@step
order: 3
text: The executor picks the next step and selects a tool from the registry.
components: C4,C8

@step
order: 4
text: Guardrails check the proposed action; risky actions wait for human approval.
components: C16,C17

@step
order: 5
text: The tool runs and returns an observation to the executor.
components: C8,C9,C10,C11,C12

@step
order: 6
text: The observation is appended to context and checkpointed.
components: C4,C13,C15

@step
order: 7
text: The critic reviews progress and the planner revises the plan; the loop repeats until done.
components: C5,C3

@step
order: 8
text: The final answer is returned and the whole trace is stored for evaluation.
components: C4,C2,C1,C18

@tradeoff
kind: pro
text: Handles open-ended, multi-step tasks that fixed workflows cannot.

@tradeoff
kind: pro
text: Tools and sub-agents extend capability without retraining the model.

@tradeoff
kind: con
text: Latency and token cost grow with every loop iteration.

@tradeoff
kind: con
text: Behaviour is non-deterministic and harder to test than a fixed pipeline.

@tradeoff
kind: risk
text: Prompt injection or a wrong tool call can trigger real side effects; limit permissions and require approval for risky actions.

@tradeoff
kind: risk
text: Loops can run away or stall, so set step, time and cost budgets.

@tradeoff
kind: scaling
text: Run steps asynchronously with checkpoints so long tasks survive failures.
