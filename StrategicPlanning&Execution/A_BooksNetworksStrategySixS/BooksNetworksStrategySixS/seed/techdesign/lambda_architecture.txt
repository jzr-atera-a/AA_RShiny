design_group: data_processing
design_type: lambda_architecture
title: Lambda Architecture
variant: Batch, speed and serving layers
summary: Lambda architecture processes the same data twice. A batch layer recomputes accurate views from the full immutable history, a speed layer computes low-latency approximate views from recent events, and a serving layer merges both so queries see complete and fresh results.
when_to_use: You need both accurate historical results and second-level freshness, and batch and streaming engines already exist in your platform.
when_not_to_use: One streaming engine can reprocess history; maintaining two code paths for the same logic is costly and error prone.
complexity: High
tags: lambda, batch, streaming, serving layer, master dataset

@step
order: 1
text: Producers send every event to the broker.
components: C1,C2

@step
order: 2
text: The broker appends events to the immutable master dataset and also feeds the speed layer.
components: C2,C3,C6

@step
order: 3
text: The batch job periodically recomputes accurate views over all history.
components: C3,C4,C5

@step
order: 4
text: The stream processor keeps real-time views for events not yet in a batch.
components: C6,C7

@step
order: 5
text: A query merges batch and real-time views.
components: C5,C7,C8

@step
order: 6
text: Consumers get complete and fresh answers, and the monitor checks both layers agree.
components: C8,C9,C10

@tradeoff
kind: pro
text: Fault tolerant: batch recomputation repairs any streaming error or code bug.

@tradeoff
kind: pro
text: Gives both low latency and high accuracy.

@tradeoff
kind: con
text: The same business logic must be written and kept consistent in two systems.

@tradeoff
kind: con
text: Operating two pipelines and a merge layer is complex.

@tradeoff
kind: risk
text: Batch and speed results can diverge and confuse users.

@tradeoff
kind: cost
text: Duplicated compute and storage for both layers.

@tradeoff
kind: scaling
text: Scale each layer independently; batch scales with history size and speed with event rate.
